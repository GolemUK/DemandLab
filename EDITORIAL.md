# Редакционная система DemandLab

Главная: практические ответы широкой аудитории. Инструменты и бизнес-разработка — отдельные направления. Сейчас опубликованы два полноценных материала, каждый на UK/EN. Пустые рубрики не получают страниц.

## Публикация материала

1. Скопируйте templates/article.uk.md и templates/article.en.md в src/content/guides/uk/ и src/content/guides/en/. Переименуйте файлы по теме.
2. Заполните заголовок, описание, category, tags и Markdown. Один translationKey связывает переводы; slug уникален в пределах языка. Существующие slug не меняйте без перенаправления.
3. Укажите реальные publishedAt, updatedAt и sourcesCheckedAt в YYYY-MM-DD. Даты не обновляются автоматически при сборке. При первом выпуске дата обновления совпадает с публикацией; затем меняйте её только после содержательного изменения. Дату источников меняйте лишь после их фактической проверки.
4. Замените пример источника проверенными прямыми официальными ссылками. Проверьте действия, предупреждения, доступность ссылок и эквивалентность двух переводов. Все ссылки Google в первом материале проверены 2026-10-16; англоязычная документация явно обозначена в UK-списке.
5. Для изображения используйте image.src из public/images, содержательный alt и необязательный caption. Заголовки H2/H3 автоматически попадают в оглавление. Markdown поддерживает таблицы, списки и блоки предупреждений через > **Увага:** / > **Warning:**.
6. relatedArticles содержит translationKey других опубликованных статей; relatedTools — order-rescue, если инструмент действительно относится к теме. Пустые связи не выводят пустые блоки. seo.title/description необязательны; по умолчанию используются основные метаданные.
7. Поставьте published: true после редакторской проверки. Черновики не попадают в маршруты, поиск, рубрики или список статей. Их схема всё равно проверяется сборкой.
8. Выполните npm run check, npm test, npm run build, npm run verify:links. Проверьте обе версии в браузере, оглавление, предупреждения, таблицы, язык и поиск. Сборка обновляет каталог автоматически.

## Рубрики

- technology — технологии и интернет
- mobile — смартфоны и приложения
- windows — Windows и компьютеры
- ai — искусственный интеллект и программы
- business — практические решения для бизнеса

Страницы /<locale>/topics/<category>/ генерируются только для рубрик с опубликованным материалом на этом языке. Не создавайте пустые страницы вручную.

## Поиск

Локальный поиск использует заголовки, описания, локализованные рубрики и теги опубликованных статей, а также рабочий Order Rescue. Все слова запроса должны встретиться в записи; регистр и варианты апострофа нормализуются. Полный текст статьи не индексируется. Запрос сохраняется в URL при отправке формы, фильтрация работает сразу при вводе. Без JavaScript остаётся полный каталог. Базы данных, внешнего поискового API и аналитики нет.

## Новые языки: pl, de, cs

Добавьте код в src/i18n/locales.ts и полный словарь в src/i18n/<locale>.ts, зарегистрируйте его в dictionaries в src/i18n/index.ts. Astro-конфигурация и схема коллекции используют единый список языков. Шаблоны главной, поиска, рубрик и статей менять не требуется. Добавьте переводы материалов с общим translationKey и локализованными slug. Sitemap и проверка ссылок распознают двухбуквенные языки автоматически. Для полной локализации существующего Order Rescue также подготовьте названия доступности, пример CSV и сообщения нового языка; проверьте инструмент отдельно. Нельзя публиковать частично переведённый словарь как готовый язык.

## SEO

SITE_URL должен содержать реальный адрес опубликованного сайта. С ним сборка создаёт canonical, hreflang и sitemap из реальных страниц. Без адреса абсолютные URL не выдумываются. Для статей используется Open Graph type=article; язык переключается на соответствующий перевод. Если перевода нет, переключатель ведёт на главную выбранного языка, а hreflang отсутствующего перевода не создаётся.

## Редакционные правила

Не публиковать автоматически поверхностные статьи, вымышленные рейтинги, статистику или обещания. Проверять интерфейсные команды по официальным источникам. Перед необратимым действием объяснять риск и проверку независимой резервной копии. Схема статей не заменяет редакторскую проверку фактов и ссылок.
