## Windows 11 працює повільно після оновлення: безпечний план відновлення

Що перевірити перед скиданням системи: диск, драйвери, автозапуск, оновлення та резервні копії.

> **Важливо**: Інтерфейси та правила сервісів можуть змінюватися. Перевіряйте актуальні дії в офіційній довідці.

## Покрокове рішення

### 1. Не починайте з перевстановлення

Запишіть дату появи проблеми, номер оновлення у «Параметри → Windows Update → Журнал оновлень» і конкретні симптоми: повільне завантаження, зависання чи проблеми з мережею. Спершу створіть резервну копію важливих файлів.

### 2. Перевірте ресурси

Відкрийте Диспетчер завдань (Ctrl+Shift+Esc), відсортуйте процеси за CPU, пам’яттю та диском. Короткочасне навантаження після оновлення може бути пов’язане з індексацією; постійне навантаження конкретного процесу потребує окремої перевірки.

### 3. Звільніть місце без ризику

Перевірте «Параметри → Система → Пам’ять». Видаляйте тимчасові файли лише після перегляду категорій. Не видаляйте папки Windows вручну та не запускайте сумнівні «оптимізатори» реєстру.

### 4. Перевірте драйвери й автозапуск

Якщо проблема стосується звуку, Wi‑Fi або відео, перевірте Диспетчер пристроїв та офіційний сайт виробника пристрою. Тимчасово вимкніть необов’язкові програми автозапуску і порівняйте час завантаження.

### 5. Використайте штатне відновлення

Спочатку встановіть доступні виправлення Windows Update. Якщо проблема чітко почалася після конкретного оновлення, розгляньте його видалення через параметри відновлення, якщо система це дозволяє. Точка відновлення доступна лише якщо її було створено.

### 6. Коли потрібна допомога

За синіх екранів, підозри на несправний диск або втрати файлів припиніть експерименти й збережіть дані. Якщо комп’ютер робочий і керується організацією, погодьте дії з адміністратором.

## Швидка перевірка

- [ ] Не використовуйте сторонні збірки Windows для «ремонту».
- [ ] Перед змінами драйверів і відновленням створіть копію даних.
- [ ] Відкат оновлення може бути недоступним після певного часу або очищення системи.
