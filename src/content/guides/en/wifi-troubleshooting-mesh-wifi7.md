## Slow or unstable Wi-Fi: diagnose first, shop later

Dropped calls do not automatically mean you need a new router. The bottleneck could be your ISP, interference, weak coverage, a busy device or poor access-point placement. Wi-Fi 7 cannot solve all of those issues.

![Wi-Fi troubleshooting diagram](/assets/wifi.svg)

## 1. Separate internet from wireless coverage

If possible, connect a computer by Ethernet and compare performance with Wi-Fi using the same service at a similar time. If Ethernet is also unstable, investigate the ISP, modem, cable and network load first.

## 2. Locate the failure

| Symptom | Likely area | First check |
|---|---|---|
| Slow only in far room | Coverage/interference | Test closer to router |
| Slow on all devices | ISP/router/load | Ethernet test |
| Slow on one laptop | Adapter/driver | Official driver updates |
| Worse in evenings | Congestion | Compare different times |
| Good speed, bad video calls | Latency or packet loss | Ping/loss checks |

## 3. Improve placement

Place the router centrally and away from metal obstacles and large sources of interference. In larger homes, an extra wired access point can be more reliable than a wireless repeater.

## 4. Understand frequency bands

2.4 GHz often reaches farther but faces more interference. 5 GHz can offer higher throughput under favorable conditions at shorter range. 6 GHz requires compatible hardware and depends on local regulations. Not every device supports every band.

## 5. When Mesh helps

Mesh can improve coverage across complex layouts, but node placement and backhaul quality matter. A mesh node connected over a weak wireless link will not create unlimited bandwidth. Wired backhaul is preferable where practical.

## 6. Should you buy Wi-Fi 7?

Only if compatible devices, network needs and budget justify it. Consider ISP speed, local transfers, Ethernet port capacity, firmware support and router processing performance. A new standard is not a cure for a faulty ISP connection or bad placement.

## 7. Secure before tuning

Update firmware from the vendor, protect router administration with a strong password, use modern supported encryption and disable unneeded remote management. Change one setting at a time and keep a record so you can roll back.

## Checklist

- [ ] Ethernet baseline tested.
- [ ] Multiple rooms tested.
- [ ] More than one device tested.
- [ ] Firmware checked.
- [ ] Router placement reviewed.
- [ ] Additional access point considered.
- [ ] Mesh/Wi-Fi 7 purchase justified by measured need.
